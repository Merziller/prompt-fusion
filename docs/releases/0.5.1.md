# Prompt Fusion 0.5.1 — 发行验证

出品：禾杨智绘工作室（绍兴市柯桥区禾杨智绘软件开发工作室）；开发：Merziller（子墨）。许可：Apache-2.0。包名、CLI、MCP工具、HTTP路径、模型环境变量和输入区按钮名称均保持原契约。

## 发行内容与证据范围

- 发布当前已修复的语义核心、自适应简洁与受限轻量路径、网络错误分类，以及撤销事务修复。
- 明确保护“让预约页面更清楚”的目标，不把增强器自己的排版选择变成用户未要求的“单段落/JSON/列表”等输出限制。
- 撤销备份在应用前建立；同一Session内组件重新挂载、临时提交状态再取消不会清除已确认备份。发送、手工改动和会话切换仍正确隔离。引用使用原生detect坐标，不用展开后的剪贴板长度。
- 相比已验证的0.5.1-dev运行文件，正式版只改变核心版本字面量。`scripts/verify-distribution.mjs`核对完整源码/测试/适配文件清单、此前已测运行字节、UI摘要、署名许可和保留的实际宿主响应。

## 不混用的验证层次

1. **当前正式源码与包**：按`npm run build`、`npm test`、`npm run check`顺序检查；正式tgz在全新目录离线安装、逐文件比对，再运行测试和验证器。机器结果在发布完成后记录，不用旧版测试数充当本次结果。
2. **独立协议客户端**：外置官方MCP SDK 1.32.2验证stdio、HTTP、Bearer HTTP的无模型及本地模型替身两种路径。该测试不是厂商智能体原生安装测试。
3. **撤销复现**：真实React 18.2.0 / Lexical 0.49.0加明确DSH Session契约夹具，与归档V0.2.0源码比较。组件重挂载、临时状态取消、引用坐标、延迟投影、生成中停止均有结果。不是已登录GUI录像，也不是历史用户点击的原样重放。
4. **实际宿主模型响应**：随附[八条保留响应](../../evals/releases/0.5.1/host-observations.json)，来自此前真实0.5.1-dev宿主调用；共17次模型调用。原稿、输出、版本及审查记录原样保留，来源说明和缺失的供应商/逐调用时间明确写出。不冒充新的8×2重复实验或原始供应商网络抓包。
5. **历史质量评测**：0.4.0十轮数据和0.5.0-dev五方比较的含义、失败和局限仍单独保留。0.5.1没有新五方总分，不挪用99.46或98.88当作正式版质量成绩。

已登录DSH GUI、DesktopIPC完整链路及其他厂商原生客户端保持NOT_RUN；当前不宣称这些维度已通过。用户反馈“验证成功”与自动化/协议证据分别记录。

## 可复现命令

```sh
npm run build
npm test
npm run check
node scripts/verify-distribution.mjs
# 下列工具需要另行提供依赖目录，依赖不打包进插件
node scripts/sdk-smoke.mjs --sdk-root /absolute/node_modules/@modelcontextprotocol/sdk
node scripts/undo-react-lexical-smoke.mjs --deps-root /absolute/ui-regression
```

历史候选清单不改写。正式版使用`evals/releases/0.5.1/manifest.json`，其`behaviorBaseline`指向原候选清单，以字节比较证明运行行为延续；署名扩展不改变上游权利。
