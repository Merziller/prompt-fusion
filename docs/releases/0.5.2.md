# 0.5.2：正式发行与验证边界

本次按维护者要求，将已公开的 0.5.2-rc.1 晋升为 **0.5.2 正式稳定版**。晋升不增加产品功能，不改写此前的测试记录。此文随发行包冻结；远端发布是否完成，以 GitHub Release 与公开附件核验回执为准。

## 版本与来源

- 包、核心、Claude 插件版本统一为 `0.5.2`。
- 晋升来源：[0.5.2-rc.1](https://github.com/Merziller/prompt-fusion/releases/tag/v0.5.2-rc.1)，源码提交 `5e42cd78a2265e3de33031384bf7d95994ce47b2`。
- 18 个运行文件相对已发布 RC，仅 `src/core.mjs` 的版本字面量变化；其余运行文件逐字节一致。发行文档、元数据、验证脚本与测试更新不计为产品行为变化。
- [稳定版清单](../../evals/releases/0.5.2/manifest.json)记录全部包内文件，保留[原 RC 清单](../../evals/releases/0.5.2-rc.1/manifest.json)及其 SHA-256，不覆盖旧标签或附件。
- 命令、MCP 工具名、HTTP 路径、环境变量、单按钮外观、Apache-2.0 与作者署名不变。

## 包含的修复

- 区分部分中文描述与真实禁止指令，减少“不好听”“不舒服”“别扭”“别人”等普通表达造成的误拦。
- 未应用增强结果时显示具体原因，并保留原稿。
- 修复清空草稿后停止受阻；保留撤销、手工编辑后的旧结果拦截与提示清理。
- 诊断仅返回有限阶段、次数、耗时和错误类别，不包含提供商正文或凭据。
- 不自动发送，也不执行提示词中的任务。

## 已知限制继续有效

窄窗口测试曾被 Desktop 渲染进程崩溃中断，原因未定；浅色/深色主题覆盖未完成。未重新运行正式版原生 GUI 或完整真实模型质量基准。稳定版标识是发行通道选择，不表示这些限制已修复或所有厂商环境均完成验证。

## 安装与回退

```sh
dsh plugin --profile desktop add https://github.com/Merziller/prompt-fusion/releases/download/v0.5.2/prompt-fusion-0.5.2.tgz
```

需要回退时，可使用保留的 [0.5.1 稳定版](https://github.com/Merziller/prompt-fusion/releases/tag/v0.5.1)。项目开源免费；所选模型服务可能计费。

## 复现

```sh
node scripts/build-client.mjs --check
node scripts/test-report.mjs
node scripts/check.mjs
node scripts/verify-current-release.mjs
npm pack --ignore-scripts --offline --pack-destination output
node scripts/smoke-current-release.mjs --archive /absolute/path/merziller-prompt-fusion-0.5.2.tgz --npm-cli /absolute/path/npm-cli.js --sdk-root /absolute/path/node_modules/@modelcontextprotocol/sdk --deps-root /absolute/path/react-lexical-fixture
```

SDK 与 React/Lexical 是验证时显式提供的依赖，不是插件运行依赖。本次 GitHub 正式发行不等于插件市场已合并收录。
