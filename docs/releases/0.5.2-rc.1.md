# 0.5.2-rc.1：发行身份与验证边界

此文随预发布包冻结，记录打包时的代码和证据范围。实际远端发布、CI 和市场状态以对应 GitHub 页面及发布回执为准；此页不把准备文件当作上传成功。

## 版本与行为

- 包：`@merziller/prompt-fusion@0.5.2-rc.1`；命令、MCP 工具名、HTTP 路径、环境变量保持不变。
- 发布性质：**预发布**，稳定版仍为 **0.5.1**。
- 源码：零运行时依赖；Apache-2.0；出品与开发署名保持不变，第三方声明和许可原文保留。
- 变化：修复有限中文描述/普通词误判；直接显示失败原因；修复空草稿停止、组件中断反馈和编辑后旧提示；保留原稿、原生撤销与旧结果防覆盖。
- 诊断：仅有限错误类别、阶段、调用数及耗时，不输出提供商正文或凭据。

## 真实现场观察，不扩张结论

候选一次真实增强把 85 字符草稿改写为 157 字符，约 10.229 秒后出现撤销；撤销精确恢复原文。实际停止在约 1.192 秒触发；另验证清空草稿后的停止、修改后提示清理、编辑期间旧结果不覆盖（约 6.184 秒后完成）以及宿主恢复后的草稿还原。所有这些测试都未发送草稿。

早期管理器返回 `restart-required / package-moved`，后来实际模型工具与新提示均证明候选已加载；旧“等待重启”记录是当时快照。不能据此保证所有机器热加载行为相同。

## 明确保留的限制

- 窄窗口测试被 Desktop 渲染进程崩溃中断；没有证据确定插件或宿主哪一方是原因。
- 浅色/深色主题覆盖未完成，故不提升为稳定版。
- 真实 GUI 没有人为注入全部网络、凭证、格式与保真失败；这些分类已有自动用例。
- RC 未单独重跑真实模型质量基准，历史四方/五方分数不挪作本版成绩。
- 其他厂商原生兼容性仍以[平台矩阵](../PLATFORMS.md)逐项标识，协议 fixture 通过不等于全平台实测。

## 重现

```sh
node scripts/build-client.mjs
node scripts/test-report.mjs
node scripts/check.mjs
node scripts/verify-current-release.mjs
npm pack --ignore-scripts --offline --pack-destination output
node scripts/smoke-current-release.mjs --archive /absolute/path/merziller-prompt-fusion-0.5.2-rc.1.tgz --npm-cli /absolute/path/npm-cli.js --sdk-root /absolute/path/node_modules/@modelcontextprotocol/sdk --deps-root /absolute/path/react-lexical-fixture
```

SDK 与 React/Lexical 是明确提供的验证依赖，不是插件运行依赖。上述命令不替换正在使用的 DSH profile。
