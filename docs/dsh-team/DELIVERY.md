# 实际研发记录

本项目按已加载的软件研发专家团与 dsh-doc 方法执行。当前会话没有可调用的团队创建/委派入口，因此由单个实现者完成研究、实现、自测和复核；没有虚构角色签字、独立 QA 或团队审查通过。

## 输入与决策

- 恢复用户指定历史会话，只提取与本项目相关的原话与源码定位。原始内容仅存私有 .local，未公开。
- 下载三个固定提交的源码，逐项读取运行入口、前端、模型提示词、语音服务和许可证；审计见 [来源报告](../SOURCE_AUDIT.md)。历史135次调用不充当本版测试。
- 用户确认 GitHub 账号 Merziller、公开 Gmail 和发布操作；同意排除 Zcode。
- 以共用核心替代拼装原插件。0.1保真追加、离线优先、预览/应用；0.2按用户实际反馈改成单按钮自动场景、smart/deep、直接写回与同按钮停止/撤销，新增保留原句的结构化编排。模型仍仅选审核规则，原生版本检查保留。
- 发现原始 webServer 路由未覆盖宿主鉴权和 Desktop 载体，发布前替换成官方 connection.fetch，并增加注册/异常/取消测试及实际401检查。

## 迭代修复
