# 禾杨灵词 0.5.2-rc.1 群更新说明

禾杨灵词（Prompt Fusion）更新到 **0.5.2-rc.1 预发布版**，这次主要修复日常使用中的几个问题：

• 减少“不好听、不舒服、别扭”等正常反馈被误判，改善部分“转完圈却没变化”的情况。
• 增强未成功时直接显示原因，不再只停下转圈；检查未通过仍保留原稿。
• 修复清空草稿后停止受阻，完善停止、撤销和编辑后旧结果防覆盖。
• 仍然只有一个增强按钮，不自动发送，也不替你执行提示词中的任务。

本版为 RC，窄窗口与主题检查仍有未完成项；求稳可继续用 0.5.1。代码开源免费，所用模型服务可能计费。

下载与说明：https://github.com/Merziller/prompt-fusion/releases/tag/v0.5.2-rc.1
