作者 Merziller。证据审阅日期 2026-11-26（Asia/Shanghai）。输入基线：指定历史会话 session-fefeadc2-1ec6-4ed7-8e14-96d573fa3132 的用户原话、三项目固定提交及历史测试报告。历史会话、模型记录和本机路径只存 `.local/`，不进入公开交付。

## 范围与验收

- R1 输入必须是非空 UTF-8 文本，单次最多 48 KiB；配置枚举、类型、上下文和输出均有上限。增强器只处理文本，不拥有执行原任务的工具或代理权限。
- R2 原文逐字保留在增强结果开头，不删除数字、代码、链接、否定词、输出语言或约束。追加的通用组织建议明确从属于原文，冲突时原文优先；不硬塞技术栈、页数、平台、日期、预算、评价或事实。语言自动识别支持中/英；其他语言原样返回并明确标记，不声称全语种增强。
- R3 领域 auto/general/code/design/office/collaboration/research/writing；强度 light/standard/deep；模式 base/lite/standard/smart/publish。base=最小补充；lite=轻量；standard=结构化；smart=可选模型选择已审查清单；publish=强调受众与交付，仍不自动发布。参数作用独立。
- R4 所有渠道复用同一核心。默认离线且免费；可选模型只选择清单 ID，不自由改写原文。模型结果采用严格 JSON 白名单，异常/超时/取消/空输出/超长/恶意输出均显式报告并可按配置回退离线。调用自选模型可能产生第三方费用，本项目无付费墙。
- R5 DSH 按钮在既有 slot 内，生成后预览；应用和撤销由用户点击，检查草稿是否变化。取消、重复点击、组件卸载、超时和服务卸载均清理。不同请求独立，不复用全局任务 ID。提供统一命令与工具的文本增强操作。
- R6 上下文和草稿记忆默认关。仅接收用户主动传入的有界文本，不扫描工作区或旧会话。上下文标记为资料，不升级为指令；疑似密钥拒绝加入上下文。记忆只在组件内存，发送/换会话/卸载清除。DSH 音频使用浏览器 WebAudio 录音与宿主公开 speechToText 服务，识别器位置先展示且不自动切换；转写先审阅再插入。其他渠道可传入转写文本，整理仅提供单列建议，原文仍保留；实体录音端到端尚未验证。
- R7 CLI/stdin/单请求 JSON、MCP stdio、Claude 插件封装、通用 Skill；为 Codex、Claude Code、Antigravity、OpenClaw、OpenCode、pi、Hermes 提供按官方路径生成的配置与安装器。生成/模拟测试不等于宿主实机兼容。Zcode 经用户同意移出。

## 架构决策

零运行依赖 ESM 核心 + CLI/MCP + DSH Host/React Client + 安装器。原文保持不变并追加有限组织指引，用严格模板消除“增强器替用户做任务”、模型新增硬约束、引号清理破坏原文等风险；代价是它不是自由改写器，无法承诺自动消除原请求中的语义矛盾。模型辅助只影响建议顺序/选择，问句和矛盾由用户决定。MCP 与 DSH 工具仅暴露增强预览，不提供发送、执行、应用或发布操作。

## 验证原则

每条 R 对应自动测试或明确 NOT_RUN。自测不标独立 QA。官方资料只证明机制存在，实际运行另列。模型不能凭静态模板测试宣布质量提升；保存测试用例与盲评材料，历史分数不混入当前结果。发布不得包含 `.local/`、会话正文、凭证、node_modules 或私人路径。
