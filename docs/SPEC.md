# Prompt Fusion 0.4.0 — 语义增强规格

2026-11-26（Asia/Shanghai），作者 Merziller。该规格取代0.2/0.3的“原文保留＋规则追加”产品行为；旧版结果仍保留在历史审计中。第十轮已满足下方冻结质量门槛；发行核心与受测核心除版本字面量外一致。安装包、CI、公开发布及市场合并分别按回执核验。

## 目标与输入

将当前草稿改写为更清楚、顺序合理、补全适度、适合原任务的提示词，而不是只在原文外增加几个标题。保留原意、语言、事实、数字、代码、否定条件、不确定性及执行阶段；增强器本身不回答或执行草稿中的任务。

- R1：请求为一个JSON对象，`input`非空，UTF-8输入最多48KiB，输出最多80KiB；选项、上下文和字典均有边界。错误不悄悄截断原文。
- R2：默认`smart/deep/structured/auto`，由模型理解完整意图并真正重组正文。明确、简短的原稿可以原样通过。深度代表适当精确和覆盖，不等于越长越好。
- R3：第一次调用生成改写，第二次逐项对照原稿审查；审查修改了文本，或机械检查仍有问题时，再进行一次复核。最终数字/字面量/原生引用位置/新增对话限制检查始终执行。模型审查不是形式证明，质量必须另行实测。
- R4：严格JSON响应；格式错误每阶段最多修正一次，所有阶段共用一个截止时间。不无限循环、不执行模型给出的代码。保真失败、模型缺失或超时默认保留原文并返回明确警告；`fallback:false`直接报告错误。取消始终报告取消，不当成成功结果。
- R5：输入区保持原来唯一的“增强／停止／撤销增强”按钮；CSS、图标、位置和控件数有冻结回归。普通文字以原生草稿版本CAS整体替换；原生引用存在时使用`append`保留精确前缀。请求期间编辑、会话切换、发送、撤销条件变化均不覆盖新内容。绝不自动发送。
- R6：DSH只读取当前草稿，使用宿主已经选定的模型，整个增强过程中固定该选择；不自动读取文件、聊天历史或凭证。继续使用DSH原生语音，没有额外麦克风按钮。高级接口可显式提供有界上下文、上一稿和语音文本建议，默认不启用。
- R7：CLI、便携Skill、MCP stdio、无状态MCP Streamable HTTP、REST/OpenAPI与DSH共用同一核心。非DSH接口仅在明确`--model`后读取`FUSION_BASE_URL`、`FUSION_MODEL`和可选`FUSION_API_KEY`。没有模型时原稿保留，不伪装成语义增强。`standard/base/lite/publish`是显式兼容旧规则模式，不参与新版语义质量结论。
- R8：Apache-2.0；保留上游MIT、Apache及NOTICE。运行时代码独立实现，原作者列来源与致谢而非虚构贡献者。评测中复现上游提示词必须标明其来源及用途，与产品运行时分开。

## 结果契约

`original`是用户原稿；`enhanced`是可供下游使用的提示词。`engine:model-rewrite`表示执行了模型改写和审查；`engine:unchanged`加警告表示没有得到有效增强。有效审查也可能保留本来就清楚的原文，不能只用字符串是否变化判断成功。

`audit`记录实际阶段数、模型调用数、审查修正和机械检查结果，不是质量分数。`changes.originalPreserved`只表示新字符串包含完整旧字符串；并不代表语义已获数学证明。`changes.reorganized`只表示内容变化。模型可能犯错，数值评分也不能掩盖关键错误。

`append`针对宿主原生引用等结构化草稿，只允许在精确原文后追加适度澄清；其作用及限制与自由重写分开说明。

## 异常与资源

模型最多4个显式提供商；每阶段最多2次格式尝试，整体默认60秒、可设10..120000毫秒。模型响应解析上限128KiB，最终输出80KiB。HTTP入口128KiB请求、并发8，鉴权、Host/Origin、取消及清理由共享传输处理。真实DSH接口使用官方connection，不使用绕开宿主身份验证的裸webServer路由。

上下文凭证模式检查只是一层误传检查，不宣称完整脱敏。调用者主动输入的文本会发送给明确配置的模型；项目不收集遥测，不借用智能体登录凭证，不提供收费模块。自选模型可能计费。

## 质量验收

严格使用冻结的[评测协议](evaluation/OPTIMIZATION_PROTOCOL.md)：12条历史输入＋12条迁移输入，每轮三款原插件与本实现共96份新输出，匿名候选、正反两种顺序、五维100分审查。两组均值至少95、每例至少90、关键错误为零才通过。失败输出和服务故障保留，不挑选成功重跑结果，不改变标准。

工程测试不计入文字质量分数；配置、SDK互通、真实DSH服务、厂商原生界面、实体语音各自记录证据。历史约61分是作者另一口径评分，不与新模型盲评混成同一量尺。
