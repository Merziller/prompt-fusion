# WorkBuddy 借鉴改进：五方同题复测协议

冻结时间：2026-11-26（实现本轮改进之前）。本轮不提交或推送 GitHub，不发布 Release，不更新市场；结果先交用户审阅。

## 比较对象

1. feiwell `dsh-enhance-prompt`：固定提交 `72524db41749dd6faa0820e58cd94dcbcd47d1e6` 的原有模型请求模板。
2. ChosenXu `dsh-prompt-enhancer`：固定提交 `4019a2cae49cdca445b0af2ff5f301ac5c2c2a02` 的原有模型请求模板。
3. Fishsb `dsh-voice-prompt-enhancer`：固定提交 `1809510556edbc3e4cc814f851e1f7d32bb38353` 的 base 模式请求模板。
4. 用户提供的 WorkBuddy 文档：两个模板逐字保留；不是官方客户端性能测试，安装包来源尚未独立核验。
5. 本轮新版 Prompt Fusion：冻结实际运行的完整 src 源码，使用自动路径和默认智能模式，不手工写入候选输出。

原三插件复用以前实际记录的请求：已有同题模板沿用该题；没有同题记录时，用其开发 brief 模板仅替换输入。模式、模板优劣和上下文未全覆盖，故比较的是这些固定文本增强路径，不是整个产品。

## 数据、实现范围及调用条件

- 沿用前次 WorkBuddy 对照的全部32条输入（24条历史校准＋8条新增场景）；不丢弃任何失败案例。
- 在编写本轮自适应实现前再冻结8条简单任务／保护边界探针：中文概括、英文概括、句子润色、翻译指令、礼貌表述；含否定条件、含引号、含多步任务三条应走完整审查。它们是作者构造的专项探针，不是随机采样或独立保留集。
- 40题×5候选＝200条全新生成记录；同一生成服务 `deepseek-official/deepseek-v4.1-flash`，temperature 0.2、reasoning off、单次输出上限8192 token。实际模型调用次数按路径记录，不把多阶段视为一次。
- 不含自动任务执行、网页访问、真实客户数据；上下文及记忆关闭。原插件仅运行文本模板，不安装其原生界面。
- 用户说明前次一次服务失败源于网络代理连接。保留原始HTTP502记录及失败计分，在独立说明中记录用户解释；本轮按错误类型分别记录网络/服务、格式和内容校验失败。

本轮产品设计约束：保留既有唯一按钮的CSS、图标、位置及撤销／取消功能；不增加选项。只对短、单意图、无硬条件的文本尝试轻量编辑，并以严格表面等价检查决定是否省略第二次模型审查；不满足检查就回到完整审查。复杂输入保留现有多阶段保真流程。长度建议只约束增强器的排版，不增加下游任务要求、固定字数或硬截断。网络失败保留草稿并给出专门原因，不冒称内容不合格。

## 评分与完整性

- 使用此前冻结的五维评审系统：保真30、清晰25、相关补全20、简洁15、任务边界10，逐候选独立评分。
- 每题匿名A—E，稳定随机分配后以正序／反序分别评审；评审模型固定 `tokenshop/gpt-6-astra`，temperature 0、reasoning high、输出上限8192。80个评审请求。提高五候选JSON的响应容量，不改变评分条目或权重。
- 评审者不获知品牌、实现路径或目标分。相同输入／候选／评审模板固定哈希。只重试失败、缺失或格式无效的评审；首个有效结果保留，不重试挑高分。
- 所有生成失败均保留，包含失败的服务可用性总分按0计；另报共同成功样本的内容分，两种口径不混用。未完成双序评审的题不编造均分，报告覆盖率和缺失题。
- 分别报24条校准、8条前次探针、8条本轮探针，以及合计。自适应快速路径另列触发数、模型调用数、通过后质量与升级回完整路径次数。
- 报告实测延迟和输出长度；无实际token账单则不估算费用。重复使用同一校准集产生调优偏差，不能用有限样本承诺任意输入均高分。
- 冻结旧0.4.0源码与安装包。新版只在本地开发与复测，用户确认前不推送。
