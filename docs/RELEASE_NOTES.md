# Prompt Fusion 0.1.0

Merziller 的首个公开版本，Apache-2.0，零运行时依赖。

- 默认离线增强，逐字保留原始提示词，仅追加从属指引；模型辅助只选择审核过的规则ID。
- DSH 预览、明确应用、撤销、原生插入与过期草稿保护；官方 connection 接口、工具和命令共用核心。
- CLI、stdio MCP、七类平台的自包含 Agent Skill 安装与必要配置生成；平台机制验证与真实原生测试分别记录。
- 可选的参考资料、一稿内存、词典与语音转写审阅。录音对接宿主公开语音服务，尚未完成实体麦克风/已登录界面端到端测试。
- 123项本机自动化测试通过；真实 DSH 离线及模型辅助工具调用通过；未登录接口401。
- 原项目 feiwell / ChosenXu / Fishsb 的来源、许可与功能审计已保留；新实现未直接复制其运行时代码、提示词或图标。

请先阅读 docs/VERIFICATION.md 和 docs/PLATFORMS.md。其他智能体原生加载、实际界面与实体语音验证仍有待完成项。本插件免费，用户自选的模型/云识别服务可能计费。
