## 更新

- 语义改写、保真审查、按需复核；保留具体目标和关键约束，不擅增“一个简短段落”等下游格式。
- 简单表面等价修改可走单次快速路径；复杂请求继续完整审查。网络、代理、认证、超时、格式及保真问题分别反馈；失败保留原稿。
- 修复旧版增强后撤销记录在组件重新挂载／临时状态取消时丢失的路径，原生引用使用正确编辑坐标，增加五秒编辑确认期限。
- DSH按钮依然只有“增强／停止／撤销增强”，不新增设置面板或品牌前缀；不自动发送或执行输入中的任务。
- 保持`@merziller/prompt-fusion`、`prompt-fusion`、MCP工具名、HTTP路径和`FUSION_*`环境变量兼容。DSH、CLI、MCP、REST与自包含Skill共用核心。
- 补全工作室出品信息与双版权。Apache-2.0正文、上游版权与许可声明保留；项目代码免费，用户配置的模型服务可能计费。

## 验证与限制

正式文件清单与前期已测0.5.1-dev运行字节比对，仅核心版本字面量变化。构建、回归测试、独立离线归档安装、官方SDK六种组合和React/Lexical撤销复现分别留有机器回执。另附8条实际宿主工具响应（17次模型调用）的原始可见结果投影；不是新的完整质量评测或供应商原始流量。

已登录DSH GUI、其他厂商原生客户端的未测范围继续标注。历史0.4.0与0.5.0-dev比较中的均分和失败保持历史身份，0.5.1不宣称获得新的五方分数或普遍语义保证。
