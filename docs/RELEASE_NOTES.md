## 这次更新

- 修复部分“转圈结束、草稿却没变”的误拦：更准确地区分“不好听”“不舒服”“别扭”“别人”等描述/普通词与真正的禁止指令。并非保证每次都改写；真正未通过检查时仍保留原文。
- 失败不再只有悬停提示：直接显示保真、格式、连接、限流、凭证、超时或中断等原因。
- 修复清空草稿后停止受阻；生成中改稿后，旧结果不会覆盖新稿，编辑也会清除过时提示。
- 保持一个“增强／停止／撤销增强”按钮，不自动发送，不执行提示词里的任务，不增加默认数据采集。
- 失败诊断仅包含有限阶段、调用数、耗时与类别，不包含提供商错误正文或密钥。

## 验证与已知限制

七项真实 DSH 交互检查在 **0.5.2-dev.0** 上完成，涵盖增强、撤销、停止、空草稿停止、提示清理、编辑期间旧结果拦截与宿主恢复。**本 RC 的 18 个运行文件与该候选一致，仅核心版本字面量改变**；这不是 RC 独立 GUI 重测。原始用户草稿、会话数据及本机路径不随发行上传。

本版使用独立发行清单、文件哈希和真实归档离线安装验证；另运行完整自动测试、官方 MCP SDK 六组和真实 React/Lexical fixture。历史发行清单与质量分数保留原身份，不作为本版的新成绩。源码 CI 与公开附件下载结果分别核验。

**仍为预发布：**窄窗口检查中 Desktop 渲染进程曾崩溃，原因未定；浅色/深色主题覆盖未完成。未重跑完整真实模型质量基准，不保证所有输入或所有厂商原生应用均适用。0.5.1 继续作为稳定版。
